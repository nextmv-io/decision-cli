# Decision CLI

Welcome to `decision`, a CLI for decision ops. This is a mirror of the [Nextmv
CLI][cli-docs], with the sole difference that the command structure is
`decision` instead of `nextmv`.

📖 To learn more visit the [Nextmv CLI docs][cli-docs].

## Installation

Requires Python `>=3.10`. Install using the Python package manager of your
choice:

- `uv`

    ```bash
    uv tool install decision-cli
    ```

- `pip`

    ```bash
    pip install decision-cli
    ```

- `pipx`

    ```bash
    pipx install decision-cli
    ```

To verify installation, run:

```bash
decision --help
```

For a quick start, run:

```bash
decision init
```

[cli-docs]: https://docs.nextmv.io/cli
